## DEF & MDEF 减伤公式

### 物理减伤
```
减伤% = (DEF + VIT) × 0.8  (上限90%)
实际伤害 = 攻击力 × (1 - 减伤%) - VIT×0.8
```

### 魔法减伤
```
减伤% = MDEF × 0.8
实际伤害 = 魔法攻击力 × (1 - 减伤%)
```

---

## ASPD 攻击速度

```
ASPD = 200 - (250 - AGI - DEX/4) × (200 - 武器基础ASPD) / 250
```
ASPD 上限为 190（每秒约5次攻击）。

---

## HIT / FLEE / CRI

```
HIT = BaseLv + DEX + 装备HIT补正
FLEE = BaseLv + AGI + 装备FLEE补正
CRI = LUK/3 + 装备CRI补正 + 1

命中率 = 80 + HIT - FLEE  (最低5%)
暴击无视FLEE，必定命中
完全回避 = LUK/10 + 装备完全回避补正 (最高触发)
```
